# 大屏前端说明（ECharts + HTML + CSS + JavaScript）

> 这份文档只有一个目的：**让你自己会改。** 每一段代码"管什么、改哪里、改了会怎样"都在下面。

---

## 一、怎么打开、怎么改

| 你想做的事 | 怎么做 |
|---|---|
| 看效果 | 用 VS Code 打开 `web` 文件夹 → 在左侧文件树里右键 `index.html` → **Reveal in File Explorer** → 双击。浏览器直接渲染，不需要装任何东西、不需要联网 |
| 改代码 | VS Code 里直接编辑 `index.html` / `css/style.css` / `js/charts.js` / `js/main.js` |
| 改完刷新 | `Ctrl + S` 保存 → 浏览器按 `F5` |
| 推荐插件（可选） | VS Code 装 **Live Server**，右键 `index.html` → *Open with Live Server*，保存后浏览器自动刷新，不用手动 F5 |

> 为什么双击就能开？因为 ECharts 库、地图轮廓、数据**全部下载到了本地**（`js/lib/`、`js/china-map.js`、`js/data.js`），所以断网也能演示。

## 二、文件清单：谁负责什么

```
web/
├── index.html            ① 骨架：页面上有哪些块、每块放哪个图表容器
├── css/
│   └── style.css         ② 外观：配色、字号、间距、卡片发光、三列宽度与行高比例
├── js/
│   ├── lib/
│   │   ├── echarts.min.js          官方画图引擎（5.5.1，勿改）
│   │   └── echarts-wordcloud.min.js 词云插件（勿改）
│   ├── china-map.js      ③ 中国地图轮廓数据（169KB，脚本自动生成，勿手改）
│   ├── data.js           ④ 大屏数据（35KB，脚本自动生成，勿手改）
│   ├── charts.js         ⑤ 每张图的配置 ★改图主要在这里★
├── main.js               ⑥ 启动：缩放、填 KPI 数字、时钟、自适应
├── 预览截图.png          大屏整体效果（1920×1080，可直接放进报告）
└── 说明文档.md           本文件
```

**加载顺序不能乱**（写在 `index.html` 底部）：echarts → 词云插件 → 地图 → 数据 → charts.js → main.js。
前四个是"料"，`charts.js` 是"做法"，`main.js` 是"开火"。

## 三、`index.html`：骨架（改布局看这里）

从上到下就是大屏的五块：

| 段落 | 标签 | 作用 |
|---|---|---|
| 顶栏 | `<header class="top-bar">` | 标题 + 右上角"数据更新/时钟" |
| KPI 行 | `<section class="kpi-row" id="kpiRow">` | 6 张数字卡，**内容是空的**，由 `main.js` 的 `KPI_LIST` 填 |
| 主区 | `<main class="main-grid">` | 里面三个 `<div class="col">`＝左/中/右三列 |
| 底栏 | `<section class="card bottom-card">` | 短评年份趋势（整行） |
| 页脚 | `<footer>` | 数据来源一行字 |

**一张图 = 一个 `<div class="card">`**：

```html
<div class="card">
  <h3>类型 TOP10</h3>                              <!-- 卡片标题 -->
  <div class="chart h230" id="chartGenre"></div>   <!-- 画布：id 必须和 charts.js 里一致 -->
</div>
```

- `id="chartGenre"` 是 `charts.js` 找容器的钥匙；
- **图的高度不用写死**：图表容器 `.chart` 设了 `flex: 1`，会自动占满卡片里标题之外的剩余空间；每列多高由下面第九节的 `.col-3 / .col-map` 行比例控制。想单独固定某张图的高度，给它加内联 `style="height:200px"` 即可；
- **加减图表**：复制一个 `<div class="card">` 改标题和 id，再去 `charts.js` 照抄一个 `buildXxx()` 函数，最后在 `initAllCharts()` 里加一行。

## 四、`css/style.css`：外观（改配色看最上面）

### 1) `:root` 变量区 —— 改这里 90% 的 UI 就变了

```css
:root {
  --bg-1 / --bg-2   背景渐变的两端颜色
  --card-bg         卡片底色（半透明）
  --border          卡片描边色
  --glow            卡片外发光
  --cyan            主色（标题、重点数字、柱子渐变末端）
  --text / --text-dim  正文 / 次要文字
  --title-size      卡片标题字号
  --gap             卡片之间的间距
}
```

想换主题色：把 `--cyan` 改成比如 `#ff9f43`（橙）或 `#7cffb2`（绿），整屏会跟着变。

### 2) `#stage` —— 舞台

固定 `1920px × 1080px`，`main.js` 把它等比缩放到当前窗口。**想改大屏设计尺寸就同时改这里和 `main.js` 里的 `STAGE_W/STAGE_H`。**

### 3) `.main-grid` —— 三列宽度

```css
grid-template-columns: 1fr 1.25fr 1fr;   /* 左 中 右；中间那列更宽（放地图） */
```

改成 `1fr 1fr 1fr` 就是三等分。

### 4) `.col-3` / `.col-map` —— 每列里各张图的高度比例

```css
.col-3   { grid-template-rows: 1fr 1fr 1fr; }   /* 左右两列：三张图等高 */
.col-map { grid-template-rows: 1.7fr 1fr; }     /* 中间列：地图高、散点矮 */
```

`1.7fr 1fr` 就是"地图占 63%、散点占 37%"。想让地图更大：改成 `2.2fr 1fr`。
底栏（年份趋势）的高度是 `.bottom-card { height: 176px }`。

## 五、`js/charts.js`：图表配置 ★核心★

文件结构固定为三段，找东西按这个顺序：

### 第 0 段：公共样式（改一次，所有图统一变）

| 变量 | 管什么 |
|---|---|
| `FX` | 调色板：`FX.cyan` 主色、`FX.gold` 金色、`FX.dim` 灰字……每张图都用它取色 |
| `AXIS` | 坐标轴样式（轴线颜色、刻度字色、网格线颜色），用 `...AXIS` 展开复用 |
| `TIP` | 鼠标悬停提示框的底色/边框/字色 |
| `FONT` | 全局字体族 |
| `TOP` | 排行榜类图显示多少条（现在是 10） |

### 第 1 段：`draw(id, option)`

一句话把配置画到容器上。你不用管它，只要知道：**每张图的 option 都通过它落地**。

### 第 2 段：`buildXxx()` —— 一张图一个函数

| 函数 | 图 | 图表类型（想换就改 `type`） |
|---|---|---|
| `buildGenre()` | 类型 TOP10 | 横向柱状 `bar` |
| `buildDecade()` | 年代分布 | 柱 `bar` + 折线 `line` 双 Y 轴 |
| `buildStar()` | 短评星级构成 | 环形 `pie`（`radius: ['42%','68%']` 控制圆环粗细） |
| `buildMap()` | IP 归属地 | 地图 `map` + `visualMap` 颜色标尺 |
| `buildScatter()` | 评分 × 评价人数 | 散点 `scatter`（纵轴 `type:'log'` 对数轴） |
| `buildCountry()` | 制片国家 TOP10 | 横向柱状 `bar` |
| `buildTop()` | 高分榜 TOP10 | 横向柱状 `bar`（横轴从 8.8 起，放大差距） |
| `buildWord()` | 短评高频词 | 词云 `wordCloud`（`sizeRange` 字号范围、`shape` 外形） |
| `buildYear()` | 短评年份趋势 | 折线 `line` + 渐变面积 `areaStyle` |

每个函数里的 `option` 就是 ECharts 官方文档里的那份配置对象——**想加图例、改标签、换成饼图，直接对着 [ECharts 配置手册](https://echarts.apache.org/zh/option.html) 往里加字段即可**。

### 第 3 段：`initAllCharts()`

把上面 9 个函数依次调用。**新建的图记得在这里加一行**，否则不会显示。

## 六、`js/main.js`：启动脚本（4 件事）

| 函数 | 作用 | 你想改的时候 |
|---|---|---|
| `fitStage()` | 把 1920×1080 的舞台等比缩放并居中 | 换设计尺寸时改 `STAGE_W/STAGE_H`（要与 CSS 一致） |
| `KPI_LIST` + `fillKpi()` | KPI 卡的 6 个数字 | 加一张卡：在 `KPI_LIST` 里加 `{key:'xxx', lab:'标签'}`（`key` 要存在于 `data.js` 的 `kpi` 里） |
| `tick()` | 顶栏时钟 + 数据更新时间 | 想显示日期就改格式串 |
| `noteMapTitle()` | 给地图标题补一句"海外 N 条未入图" | 不需要就删掉这个函数和它的调用 |

窗口大小变化时（`resize`）会重新缩放并让所有图表 `resize()`——这就是旋转屏幕/拖窗口后图不变形的原因。

## 七、数据从哪来（想换数据看这里）

```
豆瓣数据库 data/douban.db
        ↓  analysis/01_build_dataset.py      （清洗 + 特征工程，标准库）
analysis/analysis_movies.csv   1052 行 × 60 列
analysis/analysis_comments.csv 4695 行 × 26 列
        ↓  analysis/02_export_web_data.py    （聚合成大屏要的形状）
web/js/data.js       ← 大屏唯一的数据源
web/js/china-map.js  ← 中国地图轮廓（源：analysis/geo/china_raw.json）
```

重新生成数据（爬了新数据之后）：

```powershell
.venv\Scripts\python.exe analysis\01_build_dataset.py     # 重建两张分析表
.venv\Scripts\python.exe analysis\02_export_web_data.py   # 重建 web/js/data.js
```

`data.js` 里的结构（`window.DASH_DATA`）：

| 字段 | 内容 |
|---|---|
| `kpi` | 6 个总览数字（作品数/电影/剧集/短评/Top250/平均分） |
| `genreTop` / `countryTop` | `[{name, value}]` 排行榜 |
| `decade` | `{labels, counts, avg}` 年代分布 |
| `starDist` | 星级构成（饼图用） |
| `mapData` / `mapMax` / `overseas` | 省级短评数、最大色阶值、海外条数 |
| `scatter` | `[[评分, 评价人数, 片名], ...]` |
| `topMovies` | 高分榜 `[{name, rating, votes, year, genres}]` |
| `yearTrend` | `{labels, values}` 短评年份趋势 |
| `wordCloud` | `[{name, value}]` 高频词 |

## 八、常见改动速查表

| 我想…… | 改哪里 |
|---|---|
| 换主题色 | `style.css` 的 `:root --cyan`（以及 `charts.js` 的 `FX`） |
| 某张图变高/变矮 | `style.css` 里该列的 `grid-template-rows`（如 `.col-map { 1.7fr 1fr }`），或给单个 `.chart` 加内联高度 |
| 三列宽度不一样 | `style.css` 的 `.main-grid { grid-template-columns }` |
| 排行榜显示 15 条而不是 10 | `charts.js` 里的 `const TOP = 10` |
| 换图表类型（柱→折线/饼） | 对应 `buildXxx()` 里 `series[0].type` |
| 换配色方案 | `charts.js` 的 `FX` + 每个 `buildXxx()` 的 `itemStyle.color` |
| 词云字号/形状 | `buildWord()` 里的 `sizeRange`、`shape` |
| 加/删一张图 | `index.html` 加减 `<div class="card">` + `charts.js` 加减 `buildXxx()` + `initAllCharts()` |
| 地图换配色 | `buildMap()` 的 `visualMap.inRange.color` 数组 |
| 散点图改成对数/线性 | `buildScatter()` 的 `yAxis.type`（`'log'` ↔ `'value'`） |
| KPI 换数字 | `main.js` 的 `KPI_LIST`（数据在 `data.js` 的 `kpi`） |
| 大屏整体变大变小 | `style.css` `#stage` 与 `main.js` `STAGE_W/STAGE_H` |

## 九、已知事项

- **数据和地图都是本地文件**，所以断网可演示；但 `data.js`/`china-map.js` 是"生成物"，改了会被下次运行脚本覆盖。
- 词云用的分词：装了 `jieba` 就用 jieba，否则用二字词兜底（兜底效果明显更差，建议保留 jieba）。
- 地图只画中国省份；`ip_location` 里的"美国/日本…"计入 `overseas`，展示在地图标题里。
- 星级图里"未评分"那一块来自豆瓣未打分短评（81 条）。
