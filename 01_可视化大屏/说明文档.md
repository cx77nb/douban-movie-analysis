> 这份文档只有一个目的：**让你自己会改。** 每一段代码"管什么、改哪里、改了会怎样"都在下面。

## 一、怎么打开、怎么改

| 你想做的事 | 怎么做 |
|---|---|
| 看效果 | 用 VS Code 打开 `web` 文件夹 → 在左侧文件树里右键 `index.html` → **Reveal in File Explorer** → 双击。浏览器直接渲染，不需要装任何东西、不需要联网 |
| 改代码 | VS Code 里直接编辑 `index.html` / `css/style.css` / `js/charts.js` / `js/main.js` |
| 改完刷新 | `Ctrl + S` 保存 → 浏览器按 `F5` |
| 推荐插件（可选） | VS Code 装 **Live Server**，右键 `index.html` → *Open with Live Server*，保存后浏览器自动刷新，不用手动 F5 |

> 为什么双击就能开？因为 ECharts 库、地图轮廓、数据**全部下载到了本地**（`js/lib/`、`js/china-map.js`、`js/data.js`），所以断网也能演示。

## 三、`index.html`：骨架（改布局看这里）

从上到下就是大屏的五块：

| 段落 | 标签 | 作用 |
|---|---|---|
| 顶栏 | `<header class="top-bar">` | 左：筛选按钮 `#chipBar`（由 main.js 生成）· 中：标题 · 右：数据更新/时钟 |
| KPI 行 | `<section class="kpi-row" id="kpiRow">` | 6 组「大数字 + 小标签」，**没有卡片底色**，内容是空的，由 `main.js` 的 `KPI_LIST` 填 |
| 主区 | `<main class="main-grid">` | 里面三个 `<div class="col">`＝左/中/右三列 |
| 底栏 | `<section class="card bottom-card">` | 短评年份趋势（整行） |
| 页脚 | `<footer>` | 数据来源一行字 |

**一张图 = 一个 `<div class="card">`**：

```html
<div class="card">
  <h3><span class="idx">01</span>类型 TOP10</h3>    <!-- 标题：前面的 01 是分区编号 -->
  <div class="chart" id="chartGenre"></div>        <!-- 画布：id 必须和 charts.js 里一致 -->
</div>
```

- `<span class="idx">01</span>` 是标题前面的淡色分区编号，**不想要删掉这一段即可**；
- `id="chartGenre"` 是 `charts.js` 找容器的钥匙；
- **图的高度不用写死**：图表容器 `.chart` 设了 `flex: 1`，会自动占满卡片里标题之外的剩余空间；每列多高由下面第九节的 `.col-3 / .col-map` 行比例控制。想单独固定某张图的高度，给它加内联 `style="height:200px"` 即可；
- **加减图表**：复制一个 `<div class="card">` 改标题和 id，再去 `charts.js` 照抄一个 `buildXxx()` 函数，最后在 `initAllCharts()` 里加一行。

## 四、`css/style.css`：外观（改配色看最上面）

### 1) `:root` 变量区 —— 改这里 90% 的 UI 就变了

```css
:root {
  /* 底色：近黑（纯黑显得硬，近黑才有层次） */
  --bg / --bg-2        页面底色
  --surface            卡片底色（比页面亮一档）
  --surface-2          次级底色（悬停/隔行）

  /* 结构线：白色低透明度，比彩色线高级 */
  --line               发丝线（卡片边框、KPI 之间、标题下方）
  --line-strong        稍亮一点（筛选按钮描边）

  /* 文字三级 */
  --text               主文字（#eceff2，不是纯白）
  --text-dim           次要文字
  --text-mute          最弱：编号、单位、脚注

  /* 强调色：只有一个 */
  --accent             铜金 #e8b95f  ← 换主题色只改这三行
  --accent-soft / --accent-line

  --dot                背景点阵颜色（很淡）
  --title-size         卡片标题字号
  --gap / --radius     间距 / 圆角
}
```

**想换主题色：只改 `--accent`（CSS）和 `FX.accent`（charts.js）两个值**，整屏会跟着变
（现在的角色分工是：铜金只出现在"选中项、第一名、关键数字"上，其余全是中性灰白）。

> 这一版（2026-10-20 晚）专门重做了配色：原来的青色 `--cyan`、卡片发光 `--glow`、
> 半透明底 `--card-bg`、彩色描边 `--border` **都已删除**。如果你在旧教程/笔记里看到这些变量名，
> 那是上一版，现在的对应关系是：`--cyan` → `--accent`，`--glow`/`--border`/`--card-bg` → `--line` + `--surface`。

### 2) `#stage` —— 舞台

固定 `1920px × 1080px`，`main.js` 把它等比缩放到当前窗口。**想改大屏设计尺寸就同时改这里和 `main.js` 里的 `STAGE_W/STAGE_H`。**

### 3) `.main-grid` —— 三列宽度

```css
grid-template-columns: 1fr 1.3fr 1fr;   /* 左 中 右；中间那列更宽（放地图） */
```

改成 `1fr 1fr 1fr` 就是三等分。

### 4) `.col-3` / `.col-map` —— 每列里各张图的高度比例

```css
.col-3   { grid-template-rows: 1fr 1fr 1fr; }    /* 左右两列：三张图等高 */
.col-map { grid-template-rows: 1.75fr 1fr; }     /* 中间列：地图高、散点矮 */
```

`1.75fr 1fr` 就是"地图占 64%、散点占 36%"。想让地图更大：改成 `2.2fr 1fr`。
底栏（年份趋势）的高度是 `.bottom-card { height: 168px }`。

### 5) 视觉改版的细节（2026-10-20）

| 效果 | 改哪里 | 说明 |
|---|---|---|
| 背景点阵 + 顶部微光 | `html, body` 的 `background-image` + `--dot` | 两层背景：层 1 是顶部一点暖色光晕（`rgba(232,185,95,.055)`），层 2 是 1px 圆点（`background-size: 24px 24px`）。点要更淡就调小 `--dot` |
| KPI 大数字 + 小标签 | `.kpi` / `.kpi .val` / `.kpi .lab` | 无底色无描边，`50px` 白数字（`letter-spacing:-2px` 收紧）+ `10px` 宽字距小标签 + `--line` 竖线分区 |
| 卡片标题的分区编号 | `index.html` 的 `<span class="idx">01</span>`；样式 `.card > h3 .idx` | 编号用最弱的 `--text-mute`，不抢标题；标题下方细线是 `.card > h3` 的 `border-bottom` |
| 标题渐变字 | `<span class="grad">影视</span>`；样式 `.top-bar h1 .grad` | `background-clip: text`，色标 **白 → 铜金**（92deg）。色标别超过 3 个，否则两三个字会糊成白 |
| 标题右端小字注释 | `.card > h3 .meta` | 由 `main.js` 的 `noteMapTitle()` 动态插入，`margin-left:auto` 推到最右 |
| 副标题的真实数字 | `.kicker` + `main.js` 的 `fillKicker()` | "DOUBAN FILM DATA · 1052 WORKS · 4695 REVIEWS…" 全部由 `data.js` 的 `kpi` 生成，不会写死 |

#### 配色规则（这一版最重要的改动）

| 规则 | 具体做法 | 为什么 |
|---|---|---|
| 只留一个强调色 | 铜金 `--accent` / `FX.accent`，只出现在：选中筛选钮、排行榜第一名、评分、地图高值、词云高频、折线 | 满屏多色 = 廉价；"克制的一点颜色"才有质感 |
| 结构用线，不用发光 | 所有分隔、卡片边框都是 1px `--line`（白色 7% 透明度）；**已删除全部 `box-shadow` / `text-shadow` / 渐变描边** | 发光是"游戏 UI"，发丝线是"产品设计" |
| 数据层用中性灰 | 柱状图普通柱 `FX.bar`（白 20%），只有最大值染色 | 让读者的眼睛直接被"第一名"接住 |
| 圆角要小 | `--radius: 3px`，删掉药丸形 chip | 尖角更"利落"，大圆角显廉价 |

> ⚠️ 坑：给标题追加文字**不能用 `h3.textContent += '…'`**，那会把 `<span class="idx">` 编号整个覆盖掉。
> 要用 `document.createElement('span')` 追加（参考 `main.js` 的 `noteMapTitle()`）。

## 五、`js/charts.js`：图表配置 ★核心★

文件结构固定为三段，找东西按这个顺序：

### 第 0 段：公共样式（改一次，所有图统一变）

| 变量 | 管什么 |
|---|---|
| `FX` | 调色板：`FX.cyan` 主色、`FX.gold` 金色、`FX.dim` 灰字……每张图都用它取色 |
| `AXIS` | 坐标轴样式（轴线颜色、刻度字色、网格线颜色），用 `...AXIS` 展开复用 |
| `TIP` | 鼠标悬停提示框的底色/边框/字色 |
| `FONT` | 全局字体族 |
| `TOP` | 排行榜类图显示多少条（现在是 10） |

### 第 1 段：`draw(id, option)`

一句话把配置画到容器上。你不用管它，只要知道：**每张图的 option 都通过它落地**。

### 第 2 段：`buildXxx()` —— 一张图一个函数

| 函数 | 图 | 图表类型（想换就改 `type`） |
|---|---|---|
| `buildGenre()` | 类型 TOP10 | 横向柱状 `bar` |
| `buildDecade()` | 年代分布 | 柱 `bar` + 折线 `line` 双 Y 轴 |
| `buildStar()` | 短评星级构成 | 环形 `pie`（`radius: ['42%','68%']` 控制圆环粗细） |
| `buildMap()` | IP 归属地 | 地图 `map` + `visualMap` 颜色标尺 |
| `buildScatter()` | 评分 × 评价人数 | 散点 `scatter`（纵轴 `type:'log'` 对数轴） |
| `buildCountry()` | 制片国家 TOP10 | 横向柱状 `bar` |
| `buildRankTable()` | 高分榜 TOP10 | **不是图**：把 HTML 填进 `#rankTop`（见第十节） |
| `buildWord()` | 短评高频词 | 词云 `wordCloud`（`sizeRange` 字号范围、`shape` 外形） |
| `buildYear()` | 短评年份趋势 | 折线 `line` + 渐变面积 `areaStyle` |

每个函数里的 `option` 就是 ECharts 官方文档里的那份配置对象——**想加图例、改标签、换成饼图，直接对着 [ECharts 配置手册](https://echarts.apache.org/zh/option.html) 往里加字段即可**。

### 第 3 段：`initAllCharts()`

把上面 9 个函数依次调用。**新建的图记得在这里加一行**，否则不会显示。

| 函数 | 作用 | 你想改的时候 |

## 十、筛选条与排名表（2026-10-20 新增）

### 1) 筛选条怎么工作

三处配合，改的时候记住"数据 / 状态 / 重画"这三件事：

| 角色 | 在哪 | 干什么 |
|---|---|---|
| **数据** | `data.js` 的 `filters` | `02_export_web_data.py` 预先算好的 12 组聚合结果（3 口径 × 4 年代），离线也能切 |
| **状态** | `charts.js` 的 `STATE` | `{caliber:'all', decade:'all'}`，就是当前选中的两个选项 |
| **界面** | `main.js` 的 `buildChips()` | 按 `data.js` 的标签生成按钮，点击后改 `STATE` 并加 `.on` 高亮 |
| **重画** | `charts.js` 的 `refreshFiltered()` | 依次调用 `buildGenre/buildDecade/buildCountry/buildRankTable` |

`data.js` 里 `filters` 的形状：

```js
filters: {
  calibers: [{key:'all', label:'全部'}, {key:'movie', label:'电影'}, {key:'tv', label:'剧集'}],
  decades:  [{key:'all', label:'不限'}, {key:'1980s', label:'1980s'}, ...],
  byCaliber: { all: {decade:{labels,counts,avg}, n}, movie:{...}, tv:{...} },   // 年代分布图用
  cross: { "all|all": {genreTop, countryTop, topMovies, n}, "movie|2010s": {...}, ... }  // 其余图用
}
```

- **年代分布图（02）只吃 `byCaliber`**：用"年代"去筛年代分布没有意义；
- **类型 / 国家 / 高分榜 吃 `cross`**：键是 `口径|年代`，例如 `"movie|2010s"`；
- 地图、散点、星级、词云、年份趋势**不参与筛选**，它们的口径是全库短评。

> 加一个新维度（比如"类型"）：在导出脚本里多算一层聚合，再在 `charts.js` 的 `pick()` 里合并键值即可。

### 2) 排名表为什么不用 ECharts

`buildRankTable()` 直接把 HTML 填进 `#rankTop`，而不是画 canvas：

- 表格里的文字是**真文字**，缩放时更清晰、能被鼠标选中、能加 `title` 悬浮提示；
- 10 行严格平分卡片高度靠 CSS 一行搞定：`.rank { grid-auto-rows: minmax(0, 1fr) }`。
  **注意必须是 `minmax(0, 1fr)`**，只写 `1fr` 的话行高会被文字撑开，第 9、10 行就被裁掉了。

### 3) 星级环形图的小扇区

1 星 / 2 星 / 未评分 只占 0.6%~1.7%，硬给它们画标签必然和邻居叠在一起。
`buildStar()` 里设了 `minShowLabelAngle: 6`（角度小于 6° 不画标签），
它们的数量仍能在**下方图例**和**鼠标提示**里看到 —— 信息没丢，只是不挤在图上。

## 十一、v5 改版：衬线标题 + 全景 Banner + 深浅混排（2026-10-20）

### 1) 这一版和上一版的区别

| | 铜金版（v4） | 现在（v5） |
|---|---|---|
| 字体 | 全屏微软雅黑 | **标题全用宋体（衬线）**，正文/数字用无衬线 |
| 强调色 | 只有铜金 | 铜金（主）+ **珊瑚橘 `--hot`（辅，只用于 Banner）** |
| 底色 | 全屏近黑 | **深 + 浅混排**：KPI 行是纸感米白色块 |
| 首屏 | 直接进 KPI | 先给一句**结论 Banner**，再进 KPI |
| 叙事锚点 | 无 | Banner 巨型数字 + **环形图中间的 56%** |

### 2) 全景 Banner 怎么改

HTML 在 `index.html` 的 `<section class="banner">`，**文案是写死的、数字是动态的**：

```html
<p class="banner-line">
  <em id="bnHot">--</em> 部作品评分在 9 分以上，<br>
  却连 <span class="u">十万人</span> 都没评价过 —— 占全库 <em id="bnPct">--</em>%
</p>
```

- `#bnHot` / `#bnPct` / `#bsFive` / `#bsGood` / `#bsDecade` 由 `main.js` 的 `fillBanner()` 从 `data.js` 的 `banner` 字段填入；
- `banner` 字段由 `analysis/02_export_web_data.py` 的第 13.5 节算出（**换结论就改那里的筛选条件**）；
- 想整句换掉：直接改 `index.html` 里的文字，数字的几个 `<em>` 留着即可。

### 3) 衬线字体怎么生效（重要）

Windows 只有 `SimSun`（宋体）一个中文字体是衬线，且**只有 400/700 两档字重**。
为了让它看起来"够粗"，加了这一条：

```css
.top-bar h1, .banner-line, .kpi .val, .card > h3, .bs-item i {
  -webkit-text-stroke: .35px currentColor;   /* 细描边把笔画压粗 */
}
.kpi .lab, .chip, .kicker { -webkit-text-stroke: 0; }   /* 小字不描边，否则会糊 */
```

**坑**：小字号（≤11px）的中文衬线描边会糊成一团，所以上面的排除列表不能删。
想换成思源宋体等开源字体，把字体文件放进 `web/fonts/`，用 `@font-face` 引进来、再把 `--font-serif`
的第一个值改成它即可（注意：**双击本地文件打开时 `@font-face` 同样生效**，不需要服务器）。

### 4) 环形图中间那个大数字

`charts.js` 的 `donutCenter()` 返回一段 ECharts `graphic` 配置，挂在 `buildStar()` 的 option 上：

- 它**不是 HTML**，是画在 canvas 上的文字，所以不会挡住 tooltip；
- 位置用百分比：小字在 `top:'31%'`、大数字在 `top:'41%'`。
  **坑**：这两个值调大了大数字会掉到内圈外、调小了小字会被内圈盖住 —— 因为内圆的可用高度很小；
- 数字来自 `D.starDist` 里 `name === '5星'` 那一条，换了数据会自动跟着变。

### 5) 布局高度的连锁反应（改高度前必读）

加了 Banner（104px）之后，主区可用高度从约 660px 降到约 500px，于是：

- `.bottom-card` 从 `168px` → `152px`；
- `.kpi-row` 从 `112px` → `84px`（同时改成浅色纸感块）；
- `charts.js` 的 `const TOP` 从 `10` → **`8`**：卡片只剩约 170px，10 根横条会把标签挤到重叠；
- 类型 / 国家图的标题里写了 `TOP10`，现在由 `main.js` 的 `fixTopTitles()` 改成跟着 `TOP` 走。

**如果你想把 Banner 拿掉**：删掉 `index.html` 里整个 `<section class="banner">`，
再把 `.bottom-card` 调回 `168px`、`TOP` 调回 `10` 即可。
